SELECTED PROJECTS

Things I've built

Fire-fighting robot

A small robot that finds a fire, steers around obstacles to reach it and puts it out. It runs on its own, with no remote control and no camera.

  1. SenseFlame and temperature sensors locate the fire.
  2. SteerUltrasonic sensors guide it around obstacles.
  3. ExtinguishA relay switches the micro pump on.
  • Arduino UNO
  • Ultrasonic sensors
  • IR sensors
  • L298N driver
  • DC gear motors
  • Micro pump
  • Servo motors
  • Relay module
  • 12 V supply

RFID smart entrance

A door that opens only for a tag it recognises.

  1. ScanThe RC522 reads a 13.56 MHz tag.
  2. CheckThe Arduino judges whether it is allowed in.
  3. OpenA servo opens the door and the serial monitor logs it.
  • Arduino UNO
  • RC522 module
  • Servo motor

555 digital stopwatch

A counter that starts at zero when powered and can be stopped with a switch.

  1. PulseA 555 timer ticks once a second. A preset tunes it.
  2. CountTwo CD4033 counters tally the ticks.
  3. ShowTwo 7-segment displays show the time.
  • 555 timer
  • CD4033 ×2
  • 7-segment ×2
  • 7805 regulator
